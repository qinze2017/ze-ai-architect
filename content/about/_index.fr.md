Je suis développeur full stack et je possède plusieurs années d’expérience en développement de logiciels d’entreprise. Je concentre actuellement mon travail sur **l’architecture logicielle IA et l’automatisation intelligente**.

## Les problèmes que je peux résoudre

- Concevoir et réaliser des systèmes backend Java / Spring Boot maintenables
- Créer des applications IA combinant Python, FastAPI et les LLM
- Concevoir des modèles de données PostgreSQL, des API, des mécanismes d’authentification et des flux de travail
- Livrer des produits avec Docker, Cloudflare et CI/CD
- Partir des difficultés réelles des utilisateurs pour valider et construire progressivement un produit

## Technologies

- **Backend :** Java, Spring Boot, Python, FastAPI, REST API
- **Frontend :** React, Next.js, TypeScript, HTML, CSS
- **Données :** PostgreSQL, MySQL, SQL, Liquibase, Alembic
- **IA :** LLM, conception de prompts, extraction structurée, RAG, Agent, évaluation
**DevOps :** Docker, Linux, Cloudflare, GitHub Actions, AWS

## Langues

Chinois, français et anglais.

## Orientation actuelle

Mon objectif va au-delà du simple appel à une API d’IA : je veux devenir un architecte logiciel IA chevronné, capable d’analyser les besoins, de concevoir une architecture, d’évaluer la fiabilité, de maîtriser les coûts et de déployer en production.
