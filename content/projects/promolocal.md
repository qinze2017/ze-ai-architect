## 项目目标

帮助魁北克消费者更快识别真正值得购买的本地优惠，并降低优惠内容整理和发布的人工成本。

## 核心能力

- 商品与价格信息结构化管理
- 图片识别与优惠信息提取
- AI 辅助生成法语社交媒体内容
- 管理员审核、编辑和发布流程
- 本地门店与地区化展示

## 当前技术方向

后端使用 Python API 与 PostgreSQL，前端采用现代 Web 技术，并逐步加入缓存、幂等、审计、AI 成本控制和自动化发布能力。
